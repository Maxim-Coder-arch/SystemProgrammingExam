# Вариант 16. Библиотека системной информации

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Class Library, ProjectReference, P/Invoke, типы, разрядность

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Создать Class Library и консольное приложение-потребитель.
2. Подключить библиотеку через ProjectReference.
3. Добавить в библиотеку два публичных метода.
4. Использовать одну DLL из второго приложения.
5. Получить PID через P/Invoke GetCurrentProcessId.
6. Проверить и описать ограничения Windows API.
7. Обработать ошибку вызова нативной функции.

## Дополнительные задания
8. Добавить AssemblyVersion/FileVersion и вывести их.
9. Добавить совместимый метод-обёртку при изменении API.
10. Сравнить управляемую DLL и нативную DLL.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
